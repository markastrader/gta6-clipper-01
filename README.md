# Gun-store parking-lot fight

A vertical GTA 6 fight clip for the make.fun gta6-clipper-01 bounty. Ftug's supplied gameplay segment becomes a short fight sequence followed by an on-screen invitation to earn money making clips with AI on make.fun.

Run `node main.ts` with Node 22.18 or later. It silently copies VIDEO.json from MAKEFUN_BOT_DIR (default /bot) into MAKEFUN_OUTPUT_DIR (default /output), creating that output directory if needed. Errors go to stderr and return status 1. It uses only Node's standard library.

The video URL is a placeholder pending the coordinator's public YouTube upload. The rendered MP4 is handed over separately from this repository.
